🧠 Why adjust Scoring & Penalty Parameters? (Biological Foundations)
• Match Score (Reward): Awarded when identical amino acid residues align. Increases overall alignment score F(i,j).
• Mismatch Penalty (Substitution): Penalizes point mutations / non-identical residues. Reflects evolutionary amino acid substitution rate.
• Gap Penalty (Indel Cost): Penalizes insertions or deletions (-). A higher gap penalty (e.g. -2 or -3) forces the algorithm to align residues rather than introducing artificial gaps.

🧬 ProteoAlign Framework & Computational Foundations

This application provides a robust, bioinformatically accurate pipeline for performing global pairwise sequence alignment, multiple sequence alignment (MSA), identity matrix calculation, and automated scientific report generation. Below is a rigorous technical overview of how sequence comparison is executed.

Created by Alejandro Seco-González, 2026

⚡ 1. Global Pairwise Alignment (Needleman-Wunsch)

For any pair of protein sequences A (length N) and B (length M), the optimal global alignment is derived using dynamic programming via the Needleman-Wunsch algorithm.

F(i, j) = max {
  F(i-1, j-1) + S(Ai, Bj)   (Match / Mismatch)
  F(i-1, j) + γ              (Gap in B)
  F(i, j-1) + γ              (Gap in A)
}
  • Match (+1): Reward assigned when amino acid residues are identical.
  • Mismatch (-1): Penalty assigned when non-matching residues align.
  • Gap Penalty γ (-1): Linear score penalty applied for insertion/deletion steps.
  • Backtracking Traceback: Traces from F(N,M) back to F(0,0) to extract the optimal aligned residue strings.

🌟 2. Multiple Sequence Alignment (Star MSA)

When analyzing N > 2 sequences, exact multi-dimensional dynamic programming becomes computationally expensive. The app employs the progressive Star Alignment heuristic:

  1. Optimal Reference Selection: Evaluates pairwise similarity across all sequence pairs to select the "Star Center" sequence S* maximizing total cumulative identity.
  2. Star Center Projection: Computes global pairwise alignments between S* and each sequence Sk.
  3. Insertion Table Coordination: Tracks insertions relative to S* and pads gaps across all sequences to ensure uniform column length.
Consensus Symbols:
* = 100% Identical residue across all sequences in column
. = Conserved / Varied position (no gaps present)
  = Column contains one or more insertions/gaps (-)

📊 3. Pairwise Identity Matrix & Heatmap

Sequence Identity Percentage between any pair of sequences (A, B) is evaluated over the total length of their optimal global alignment:

Identity (%) = ( Identical Residues / Total Aligned Length ) × 100

The resulting symmetric N × N matrix is dynamically color-coded: Green (≥90%), Yellow (60-89%), and Red (<60%).

📄 4. Publication-Ready Reports & Exports

To support academic publishing and reproducible research, all results can be exported instantly:

  • LaTeX Source Code (.tex): Generates complete LaTeX source using booktabs, colortbl, and listings packages for direct insertion into research manuscripts.
  • PDF Technical Report (.pdf): Client-side PDF rendering compiled via html2pdf.js.
  • FASTA Datasets (.log): Instant sequence export for downstream bioinformatic tools.

⚖️ Biological Rationale & Impact of Custom Scoring Parameters

In bioinformatic sequence comparison, alignment algorithms search for the optimal trajectory through a scoring landscape. Modifying Match Score, Mismatch Penalty, and Gap Penalty allows researchers to model different evolutionary regimes and structural constraints:

1. Evolutionary Distance Modeling

• Closely Related Sequences: High Match rewards (+2) with moderate Gap penalties (-1) allow pinpointing exact conservation.
• Divergent Homologs: Increasing Mismatch penalties prevents spurious alignment of non-homologous residues across distant species.

2. Insertion/Deletion (Indel) Constraints

• In protein 3D structures, introducing a gap (insertion or deletion) requires a physical loop alteration or backbone rearrangement.
• A strict Gap Penalty (-2 or -3) forces Needleman-Wunsch to favor residue substitutions over creating artificial gaps.

3. Dynamic Programming Matrix & Traceback

• Parameter changes dynamically alter cell values F(i,j) = max(F(i-1,j-1)+S, F(i-1,j)+γ, F(i,j-1)+γ).
• This shifts the optimal traceback path, directly altering consensus string outputs and pairwise identity matrix values.
